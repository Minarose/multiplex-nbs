# MATLAB examples

Run each script from the repository's top folder (it adds `matlab/` to the path).

| Script | Shows |
|---|---|
| `example_01_quickstart.m` | Load the brain demo, run Multiplex-NBS, list significant components |
| `example_02_layerwise.m` | Layer-wise NBS and Multiplex-NBS on the same data |
| `example_03_your_own_data.m` | Build `W` from your own matrices and save a file Python and the app can open |
| `example_04_paired_and_glm.m` | Paired conditions, and a GLM with a covariate |

The MATLAB toolbox needs base MATLAB R2021a or newer. Run `mnbs_selftest` once after
adding the folder to your path.
