# Python examples

Install the package first (`pip install multiplex-nbs`, or `pip install -e .` from a
clone), then run any script, e.g. `python examples/python/01_quickstart.py`.

| Script | Shows |
|---|---|
| `01_quickstart.py` | Load the brain demo, run Multiplex-NBS, read components, save results and the methods text |
| `02_compare_methods.py` | Classic, layer-wise and multiplex NBS on the same data |
| `03_your_own_data.py` | Arrays, `.npz`/`.mat` files, or one ZIP per group |
| `04_paired_and_glm.py` | Paired conditions, and a GLM with a covariate |
| `05_figures.py` | Layer profile, region × layer grid and null distribution (needs matplotlib) |
